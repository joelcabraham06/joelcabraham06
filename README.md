## 🔬 Key Research & Innovative Projects

### 🧪 1. Gas Sensor Array Drift Detection & Recalibration
- **Domain**: Sensor Intelligence & Edge AI
- **Dataset**: Gas Sensor Array Drift Dataset (13,910 measurements, 16 sensors, 128 features, 6 gas classes across 10 temporal batches).
- **Novelty**: Persistence-aware, severity-controlled recalibration leveraging **Autoencoder Reconstruction Error monitoring**, Incremental PCA, and energy-aware scheduling to eliminate time-varying sensor drift without full sensor replacement.
